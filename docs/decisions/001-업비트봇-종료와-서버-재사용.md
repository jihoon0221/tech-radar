# 001. 업비트봇을 종료하고 서버를 재사용한다

- 날짜: 2026-10-26
- 결정: 모의 투자로 운영하던 업비트봇을 종료하고, 같은 NCP Micro 서버(공인 IP 유지)에 새 프로젝트를 올린다.
- 이유: 1년 무료 서버와 공인 IP를 그대로 쓰면 비용이 늘지 않고, 새 서버 구축에 드는 시간(약 하루)을 아낀다.
- 고려한 대안: 서버 반납 후 신규 생성 → 무료 혜택·IP 재설정 비용 때문에 제외.
- 정리 방식: 장부·로그·서버 `.env`를 맥에 백업 → 코드 push → 서비스·폴더 삭제 → API 키 삭제. 키는 새 프로젝트로 가져오지 않는다.
